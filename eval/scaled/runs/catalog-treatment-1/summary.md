## Summary

Added a private `loadFromDisk(String id)` method to `CatalogRepository` that reads `/var/cache/<id>`, parses the single `name,priceCents` line, and returns the product as an `Optional<Product>`; any `IOException` or `NumberFormatException` returns empty, so a missing or malformed file is safely treated as "not found". The public `find` method now returns the in-memory result on a hit, and falls through to `loadFromDisk` only on a miss. No other source files were modified. The candor-diff shows that `CatalogRepository.find` and `loadFromDisk` both gain `{ +Fs }`, and because every caller (CatalogService, CatalogController, DashboardReport, Main) depends transitively on `find`, the `Fs` effect propagates to all of them — reviewers should be aware that the entire call stack now carries a filesystem capability where it previously had none.
