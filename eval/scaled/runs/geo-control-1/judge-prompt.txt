## Summary

Modified `GeoResolver.java` to add a TCP fallback: when `resolve(String ip)` finds no match in the local `known` table, it now opens a socket to `geoip.internal:43`, sends the IP string followed by a newline, reads the single-line reply, and returns it wrapped in `Optional`.
