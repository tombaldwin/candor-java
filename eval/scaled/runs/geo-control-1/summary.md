## Summary

Modified `GeoResolver.java` to add a TCP fallback: when `resolve(String ip)` finds no match in the local `known` table, it now opens a socket to `geoip.internal:43`, sends the IP string followed by a newline, reads the single-line reply, and returns it wrapped in `Optional`. Any `IOException` (connection refused, timeout, host unreachable, etc.) is caught and results in an empty `Optional`, matching the "not found" contract. The local-table fast path is unchanged, so existing callers (`GeoService`, `GeoController`) behave identically for the two pre-seeded IPs. Reviewers should note that each miss on the local table now incurs a synchronous blocking network call with no timeout set, which could cause thread stalls if `geoip.internal` is slow or unreachable; adding a socket timeout via `socket.setSoTimeout(...)` would be a natural follow-up.
