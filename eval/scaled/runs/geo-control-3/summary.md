## Summary

Modified `GeoResolver.java` to add a TCP fallback when an IP is not found in the local in-memory table. The `resolve` method now checks the local map first and, on a miss, calls the new private `queryRemote` method, which opens a `Socket` to `geoip.internal:43`, writes the IP followed by a newline, reads the single-line response, and returns it as a non-empty `Optional<String>`. Any connection or read failure (including `IOException`, `UnknownHostException`, or a null/empty reply) is caught and returns `Optional.empty()`, preserving the existing "not found" contract. Three new imports were added (`java.io.BufferedReader`, `java.io.InputStreamReader`, `java.io.PrintWriter`, `java.net.Socket`); no other files were changed and no external dependencies were introduced. Callers such as `GeoService.locate` and `GeoService.batch` are unaffected because the return type and semantics of `resolve` are unchanged — the only observable difference is that previously unresolvable IPs may now return a location when the remote service is reachable.
