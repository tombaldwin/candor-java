## Summary

Added a `queryRemote` private method to `GeoResolver` that opens a TCP socket to `geoip.internal:43`, sends the IP followed by a newline, reads one line back, and returns it as the resolved location. The `resolve` method now checks the local in-memory table first and only calls `queryRemote` on a miss; any connection or read exception is caught and treated as "not found" (returns `Optional.empty()`). No external dependencies were added — the implementation uses only `java.net.Socket`, `java.io.PrintWriter`, and `java.io.BufferedReader` from the JDK. The candor-diff output shows that the new `Net` effect propagated transitively through every caller: `GeoResolver.resolve`, `GeoService.locate`, `GeoService.batch`, `GeoController.lookupOne`, `GeoController.lookupMany`, `GeoReport.summary`, and `Main.main` all gain `{ +Net }` — reviewers should note that any policy gating `Net` at any of those layers will now fire.
