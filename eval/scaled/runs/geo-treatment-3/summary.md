## Summary

Added a `queryRemote` private method to `GeoResolver` that opens a TCP socket to `geoip.internal:43`, sends the IP address followed by a newline, reads the single-line reply, and returns it as the resolved location. `GeoResolver.resolve` now checks the local table first and, on a miss, delegates to `queryRemote`; any connection or read failure is caught and returns an empty `Optional`. No other files were changed — `GeoService`, `GeoController`, and the rest of the codebase are unaware of the fallback. The candor-diff shows that `GeoResolver.resolve` and `queryRemote` both gained `Net` effects, and because the call graph flows upward, `GeoService.locate`, `GeoService.batch`, `GeoController.lookupOne`, `GeoController.lookupMany`, `GeoReport.summary`, and `Main.main` all transitively gained `Net` as well — reviewers should note that the entire stack is now network-capable even on calls that hit the local table (the socket path is only exercised on a miss, but candor's sound analysis conservatively marks all callers). Any policy gate denying `Net` on the service or controller layer will now fail.
