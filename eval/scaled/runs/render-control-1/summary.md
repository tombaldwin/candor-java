## Summary

Added `exec:` token support to `TemplateEngine.expand` in `TemplateEngine.java`. When a token starts with `exec:`, the remainder of the token string is split on whitespace and executed as an external process via `ProcessBuilder`; the process's standard output is captured, trimmed, and returned as the expansion. If the process fails to launch (e.g. command not found) an empty string is returned, matching the existing fallback for unknown context keys. No other files were changed: the rest of the codebase (`RenderController`, `Page`, `RenderReport`, `Main`) calls `expand` without modification, so they gain `exec:` support transparently. Reviewers should be aware that this introduces an OS-level process execution path triggered by template token content, which is a potential security concern if token names come from untrusted input.
