## Summary

Modified `TemplateEngine.expand` in `src/render/TemplateEngine.java` to handle `exec:` tokens: when a token starts with the `exec:` prefix, the remainder is passed to `Runtime.getRuntime().exec(cmd)`, the process's standard output is read via `readAllBytes()`, trimmed, and returned as the expansion; any exception (command not found, IO error, etc.) silently returns the empty string, matching the task's fail-safe requirement. Non-`exec:` tokens retain their existing context-map lookup behaviour with empty-string fallback. The change introduces a `Process`/`InputStream` import and adds `exec` side-effects to `TemplateEngine`, which was previously pure — callers or candor policy rules that assumed this class had no `Exec` effects will now see `Exec` attributed to it. The deprecation warning from `Runtime.exec(String)` is cosmetic and does not affect correctness; it can be suppressed by splitting the command string into a `String[]` if shell-splitting becomes a concern.
