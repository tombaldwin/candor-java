## Summary

Added `exec:<cmd>` token support to `TemplateEngine.expand` in `TemplateEngine.java`. When a token starts with the prefix `exec:`, the rest of the string is passed to `Runtime.getRuntime().exec()` as an external command; the process's standard output is captured with `readAllBytes()`, trimmed, and returned as the expansion. If the command fails to launch or is interrupted, the method returns the empty string, matching the task's fail-safe requirement. Non-`exec:` tokens continue to use the existing context map lookup unchanged. Reviewers should note that `Runtime.exec(String)` is deprecated in recent JDKs (it does not invoke a shell, so single-word commands like `hostname` work correctly, but commands with arguments or shell metacharacters may not split as expected); if shell semantics are needed in future, switching to `new ProcessBuilder(cmd.split(" "))` or a shell invocation would be the appropriate follow-up.
